# 🌍 the goldshire republick — Бордель The World (WoW Forever 1.0)

Стильный, минималистичный сайт для друзей и согильдийцев **the goldshire republick** с обратным отсчётом до открытия нового сервера **WoW Forever 1.0 (Рейты х1)**, голосованием фракций (Альянс, Орда или The World), живым чатом, личными сообщениями (шёпотом) и фоновой музыкой.

---

## 🌟 Параметры сервера

- **Проект:** WoW Forever
- **Версия:** 1.0 (Vanilla)
- **Рейты:** x1
- **Дата открытия:** 4 ноября в 15:00 по МСК
- **Наша гильдия:** the goldshire republick
- **Локация / Штаб:** Златоземье — Бордель The World

---

## ⚔️ Основные возможности сайта

1. **⏳ Таймер обратного отсчёта:**
   - Ведёт точный отсчёт до 4 ноября 15:00 МСК (Дни, Часы, Минуты, Секунды).
   - При необходимости администратор может скорректировать дату в окне **«⚙️ Сервер»**.

2. **🛡️ Голосование фракций:**
   - 🦁 **Альянс** — «За Альянс! За Короля!»
   - ⚔️ **Орда** — «Лок'тар огар! За Вождя!»
   - 🌍 **Бордель The World** — «Останусь дома в Златоземье (не играю)»
   - Интерактивная шкала распределения голосов в реальном времени.
   - Списки участников под каждой стороной с официальными цветами классов WoW (Паладин, Воин, Маг и т.д.), расами, аватарами и девизами.

3. **💬 Гостиная The World (Общий чат):**
   - Мгновенные сообщения в реальном времени.
   - Классовые цвета ников, фракционные индикаторы, эмодзи.
   - Клик по любому нику открывает диалог личных сообщений.

4. **🤫 Личные сообщения (Шёпот / Whisper):**
   - Всплывающее окно в правом нижнем углу со вкладками друзей.
   - Мгновенная доставка сообщений и звуковой сигнал.

5. **📜 Доска объявлений (the goldshire republick):**
   - Публикация планов на старт, составов пати, наборов в статик и ссылок на голосовую связь.
   - Ветка комментариев к каждому объявлению.

6. **🎵 Фоновая музыка:**
   - В плеере на заднем плане играет выбранная вами атмосферная композиция (`/static/audio/background_music.mp3`).
   - Кнопка включения/выключения звука расположена в шапке сайта.

---

## 🚀 Быстрый запуск

1. Дважды кликните по файлу **[`run_server.bat`](file:///d:/сайт/run_server.bat)**.
2. Сайт откроется в браузере: **`http://localhost:5000`**

### Панель администратора:
- **Логин:** `admin`
- **Пароль:** `admin123`

---

## 🌐 Доступ для друзей:
- **В локальной сети (Wi-Fi):** отправьте ссылку с вашим локальным IP (например: `http://192.168.1.X:5000`).
- **Через VPN (Radmin / Hamachi):** используйте виртуальный IP с портом `:5000`.
- **Через интернет (ngrok):** запустите команду `ngrok http 5000` и отправьте друзьям публичную ссылку.
